# Compass: A simple compass for your LLM's.

##### How to use:
```
Available commands:
/key <your-api-key>  - Set OpenRouter API key
/models             - List available models
/set <model-name>   - Set the current model
/free               - Fetch and list free models
/addmodel <model-id> [set] - Add a model by ID and optionally set as current
/pretty on|off      - Toggle pretty Markdown rendering
/chat on|off        - Toggle conversation mode
/reasoning on|off   - Toggle reasoning mode with Reasoning Tokens
/effort low|medium|high - Set reasoning effort level
/help               - Show this help message
Use Ctrl+X for newlines, Enter to submit prompt, or 'exit' to quit.
Press Up/Down arrows to cycle through prompt history, Ctrl+C to stop streaming.
Note: If keybindings don't work, try a different terminal (e.g., VS Code, iTerm2).
```

---
##### You'll need to login in openrouter to consume that. You can generate a free key to consume openrouter, huggingface and make a trial of non-free LLM's.
